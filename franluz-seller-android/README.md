# FranLuz Seller Android v1.0.0

Aplicativo Android separado para administração da FranLuz Home Decor.

- Package: `com.franluz.seller`
- Compile/Target SDK: 36 (Android 16)
- Min SDK: 23
- Destino principal: `/seller-franluz/`
- Sessão preservada pelo WebView
- Upload de mídia via seletor nativo do Android
- Câmera integrada ao seletor de imagens
- Links externos abertos fora do app
- Botão voltar integrado
- Tela offline própria
- Identidade visual FranLuz

O app Home Decor (`com.franluz.homedecor`) permanece independente.
